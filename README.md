## 🎯 What is Microsoft 365?

**Microsoft 365** is a professional office suite for PC. It includes Word, Excel, PowerPoint, Outlook and other essential productivity applications for documents, spreadsheets, presentations and email.

It offers a complete set of tools for business, education and personal use, with a familiar interface and high compatibility with common file formats.

The suite provides desktop applications optimized for Windows with reliable performance and regular feature updates.
